# E-commerce Customer Cohort & Churn Analysis

## 🎯 Business Objective
This enterprise project analyzes behavioral indicators (support tickets, tenure, device metrics) linked to customer churn to optimize retention spend.

## 🛠️ Tech Stack & Execution
* **Excel:** Derived Average Monthly Spend metrics and cross-tabulated ticket thresholds.
* **SQL:** Computed actionable Churn Rates and Risk Profiles stratified by device operational segments.
* **Power BI:** Configured diagnostic Scatter Charts isolating high-value accounts facing high-friction churn paths.
